Struttura separata:
- index.html = HTML + JavaScript
- assets/css/style.css = tutto il CSS estratto
- assets/images/ = immagini locali
- IMAGE_SOURCES.txt = URL originali
- download-images.sh / download-images.bat = scaricano le immagini originali nella cartella

Nota: il dominio sorgente non è raggiungibile dal downloader in questa sessione, quindi i file immagine originali non possono essere materializzati qui. L'HTML è già convertito ai percorsi locali.
